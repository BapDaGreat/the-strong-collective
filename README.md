## Brand Style Implementation

| Guideline | Specification Applied |
| :--- | :--- |
| **Target Audience** | Women ages 35–65; clean, elegant, warm, and confident visual tone |
| **Headline Typography** | **Cormorant Garamond** (`YOUR STRONG STARTS HERE.`) |
| **Supporting Typography** | **Lato** (`THE STRONG COLLECTIVE` & `TRAIN THE MIND. THE BODY FOLLOWS.`) |
| **Primary Colors** | Warm Ivory (`#F7F3E8`) and Deep Green (`#183D2D`) |
| **Accent Colors** | Subtle Gold (`#B59645`) and Chartreuse (`#DDF20A` / `#D7DF21`) |
| **Proportions & Realism** | Preserved 100% natural 1:1 facial features and body proportions; extended left architectural wall for true wide desktop banner proportions (`1920 × 800`) without horizontal stretching; retouched AI artifacts on foot and hand |
| **Layout & Spacing** | Generous warm ivory negative space on the left wall with >220px breathing room before the doorway edge and subject |
